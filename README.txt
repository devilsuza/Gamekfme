COMPLETE HRMS PACKAGE

FIRST RUN
1. Install Python 3.10 or newer and select Add Python to PATH.
2. Double-click install_and_run.bat.
3. Open http://127.0.0.1:5000

NEXT RUNS
- Double-click run.bat.

LOGO
- Put company logo at static/fresmart.png

FEATURES INCLUDED
- Employee own monthly roster view
- Shift A, Shift B and Weekly Off display
- English and Portuguese selector for employee/admin
- Developer English only
- Store isolation
- Employee cards and ID cards
- Roster matrix and Excel export
- Leave management
- Payroll and attendance modules
